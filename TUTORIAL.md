# Project documentation

This tutorial described the original GeoPin prototype and referenced routes and data contracts that have since been replaced. Use the maintained guides instead:

- [Project README](README.md)
- [Spanish README](tradme_es.md)
- Interactive in-app guide at `/docs`

The v2 application uses dynamic schemas, MongoDB-backed persistence, and an IndexedDB sync outbox. Prototype instructions for `/api/pins` and `PinFormData` no longer describe the current application.
